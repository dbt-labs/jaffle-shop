# Project skills

Store project-local AI skills in this directory.

Recommended structure:

- `.agents/skills/<skill_name>/SKILL.md`
- optional supporting files alongside `SKILL.md` such as `examples.md`, `checklist.md`, or `queries.sql`

A minimal skill usually includes:

- when to use the skill
- the repo conventions it should follow
- the steps to execute
- validation guidance

A starter example is included in `.agents/skills/example-project-skill/SKILL.md`.
